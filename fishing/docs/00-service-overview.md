# FishRank - 서비스 개요 및 비전

## 한 줄 정의

> **낚시인을 위한 올인원 플랫폼** — 기록·랭킹·대회·커뮤니티를 한곳에서

---

## 왜 만드는가?

### 기존 낚시 커뮤니티의 한계

| 플랫폼 | 형태 | 문제점 |
|---|---|---|
| 디시인사이드 낚시 갤러리 | 자유 게시판 | 인증샷 중심, 랭킹 없음 |
| 네이버 카페 낚시 동호회 | 지역 모임 | 비공개적, 비교 불가 |
| 루리웹 낚시 게시판 | 커뮤니티 | 기록·랭킹과 분리됨 |
| 피싱코리아 | 정보 중심 | 사용자 간 경쟁 구조 없음 |

**→ 기록 인증, 랭킹, 대회, 커뮤니티가 하나로 연결된 서비스는 국내에 거의 없다.**

---

## 핵심 가치 제안

```
기존: 사진 올리고 "잘 잡았다" 칭찬받기
FishRank: 기록을 남기고, 순위를 확인하고, 낚시인들과 이야기하기
```

1. **줄자 인증 기록** — 사진으로 잡은 물고기 길이를 공식 기록으로 남김
2. **공정한 랭킹** — 어종별·주간 순위로 전국 낚시인과 경쟁
3. **커뮤니티** — 포인트 정보, 낚시 이야기, 질문·답변을 자유롭게 공유
4. **대회** — 무료·유료 온라인 낚시 대회 참가
5. **낚시 정보** — 날씨, 매듭법, 금지구역 등 실용 정보 제공

---

## 서비스 구성

| 영역 | 설명 |
|---|---|
| **기록 & 랭킹** | 줄자 인증 기반 낚시 기록, 어종별·주간 랭킹 |
| **커뮤니티** | 자유 게시판, 댓글, 작성자 프로필 연동 |
| **대회** | 온라인 낚시 대회 개최·참가·순위 |
| **어종 사전** | 어종별 정보, 서식지, 낚시 팁 |
| **낚시 정보** | 날씨, 매듭, 금지구역, 안전 수칙 |
| **프로필** | 내 기록 + 작성 글을 한눈에 (공개/비공개) |

## 서비스 단계별 로드맵

> 기준일: 2026-08 · ✅ 완료 · 🔄 진행 중 · ⏳ 예정

### Phase 1 - MVP (웹 버전 우선) — **대부분 완료**
- ✅ 회원가입 / 로그인 (이메일 JWT)
- ✅ 사진 업로드 + 줄자 인증 (FastAPI AI 연동)
- ✅ 랭킹 (어종별 / 주간 / 지역별)
- ✅ 커뮤니티 (글쓰기, 댓글, 프로필 연동)
- ✅ 대회 (목록, 참가, 어드민 관리) — 무료
- ✅ 어종 사전, 낚시 정보, 날씨·출조
- 🔄 AI 분류 정확도·데이터셋 고도화 (목표 top-1 80%)

### Phase 2 - 검증 후 확장
- ⏳ AR 교차검증 추가 (모바일)
- ⏳ 팔로우 / 피드
- ✅ 지역별 랭킹 (Phase 1에 선행 구현)
- ⏳ 소셜 로그인 (카카오, 구글)

### Phase 3 - 모바일 앱 + 수익화
- ✅ Expo 모바일 앱 (카메라 인증 업로드 포함, 기능 패리티)
- ⏳ 스토어 출시 (iOS / Android)
- ⏳ 유료 대회 참가 (에스크로 결제)
- ⏳ 낚시 브랜드 광고 연동
- ⏳ 프리미엄 통계 구독

## 수익 모델 (하드웨어 없이)

| 항목 | 설명 |
|---|---|
| 유료 대회 참가비 | 온라인 낚시 대회 개최 |
| 낚시 브랜드 광고 | 타겟 광고 (낚시인 대상) |
| 프리미엄 통계 | 내 기록 심층 분석, 포인트 정보 |
| 대회 운영 SaaS | 낚시 클럽/대회 주최자용 |

## 웹 vs 앱 전략

| 기능 | 웹 | 앱 (Expo) |
|---|---|---|
| 커뮤니티 / 랭킹 / 대회 | ✅ | ✅ |
| 카메라 촬영 + 기록 업로드 | ✅ (파일·웹캠) | ✅ (주력, 가이드·센서) |
| 가이드 오버레이 | ✅ | ✅ |
| AR 측정 교차검증 | ❌ | ⏳ (예정) |
| 푸시 알림 | ❌ | ⏳ (예정) |

**→ 웹·Expo로 커뮤니티·랭킹·대회·인증 업로드까지 구현 완료. AR·푸시·스토어 출시는 이후 단계.**
