FishRank(이하 "서비스")는 이용자의 개인정보를 중요시하며, 「개인정보 보호법」 및 관련 법령을 준수합니다.

---

## 제1조 (수집하는 개인정보 항목)

### 필수 수집 항목

| 수집 시점 | 항목 |
|---|---|
| 이메일 회원가입 | 이메일 주소, 비밀번호(암호화 저장), 닉네임 |
| 카카오 소셜 로그인 | 카카오 계정 이메일, 카카오 고유 ID, 닉네임 |
| 낚시 기록 업로드 | 사진 파일, 업로드 일시 |

### 선택 수집 항목

| 수집 시점 | 항목 |
|---|---|
| 낚시 기록 업로드 | GPS 위치 정보(위도/경도), 낚시 장소명, 메모 |
| 프로필 설정 | 프로필 사진 |

### 서비스 이용 과정에서 자동 수집되는 항목

- 서비스 이용 기록, 접속 로그, IP 주소
- 기기 정보 (브라우저 종류, OS 정보)
- 쿠키 (로그인 세션 유지 목적)

## 제2조 (개인정보 수집 목적)

| 목적 | 수집 항목 |
|---|---|
| 회원 식별 및 인증 | 이메일, 비밀번호, 카카오 ID |
| 서비스 제공 (기록·랭킹) | 닉네임, 사진, 어종 측정 결과 |
| 위치 기반 서비스 (선택) | GPS 위치 정보 |
| 불법 이용 방지 및 분쟁 해결 | 접속 로그, IP 주소 |
| AI 어종·크기 분석 | 업로드된 사진 |
| 서비스 개선 및 통계 분석 | 서비스 이용 기록 |

---

## 제3조 (개인정보 보유 및 이용 기간)

| 항목 | 보유 기간 |
|---|---|
| 회원 정보 | 회원 탈퇴 후 30일 (복구 요청 대비) |
| 낚시 기록 및 사진 | 회원 탈퇴 후 즉시 삭제 (단, 랭킹 보존 목적의 익명화 데이터는 제외) |
| 접속 로그 | 3개월 |
| 결제 관련 정보 | 관련 법령에 따라 5년 |

**법령에 의한 보존**:
- 전자상거래 등에서의 소비자보호에 관한 법률: 5년
- 통신비밀보호법에 따른 로그 기록: 3개월

---

## 제4조 (개인정보 제3자 제공)

서비스는 원칙적으로 이용자의 개인정보를 외부에 제공하지 않습니다.  
다만, 아래의 경우에는 예외로 합니다:

- 이용자가 사전에 동의한 경우
- 법령의 규정에 의거하거나, 수사 기관의 적법한 절차에 의한 요청이 있는 경우

---

## 제5조 (개인정보 처리 위탁)

서비스는 원활한 운영을 위해 아래와 같이 개인정보 처리를 위탁합니다:

| 수탁업체 | 위탁 업무 | 보유 기간 |
|---|---|---|
| Amazon Web Services (AWS) | 서버 운영, 이미지 파일 저장 (S3) | 위탁 계약 기간 동안 |
| Kakao Corp. | 카카오 소셜 로그인 인증 처리 | 해당 없음 (카카오 서버에 저장 안 함) |

---

## 제6조 (사진 데이터 및 AI 처리)

이용자가 업로드한 사진은 다음과 같이 처리됩니다:

1. **저장**: AWS S3 버킷에 암호화하여 저장
2. **AI 분석**: 어종 분류 및 줄자 길이 인식 목적으로 자동 분석
3. **서비스 표시**: 랭킹 및 기록 페이지에 공개 표시 (이용자가 공개 설정한 경우)
4. **모델 개선**: 이용자 동의 하에 AI 모델 학습에 활용 가능

> **GPS 위치 정보**: 낚시 기록 업로드 시 위치 제공은 **선택 사항**입니다.  
> 위치 정보를 제공하지 않아도 서비스 이용에 제한이 없습니다.

---

## 제7조 (이용자 권리)

이용자는 언제든지 아래의 권리를 행사할 수 있습니다:

| 권리 | 방법 |
|---|---|
| 개인정보 열람 | 마이페이지 → 내 정보 확인 |
| 개인정보 수정 | 마이페이지 → 프로필 편집 |
| 개인정보 삭제 | 마이페이지 → 회원 탈퇴 |
| 개인정보 처리 정지 | 이메일 문의 (privacy@fishrank.kr) |
| 낚시 기록 삭제 | 개별 기록 → 삭제 버튼 |

---

## 제8조 (개인정보 보안 조치)

- 비밀번호: bcrypt 단방향 암호화 저장
- 전송 구간: HTTPS(TLS 1.2 이상) 암호화
- DB 접근: 최소 권한 원칙 적용
- S3 이미지: 버킷 퍼블릭 접근 제한, 서명된 URL 사용
- 접근 로그: 비인가 접근 모니터링

---

## 제9조 (쿠키 사용)

서비스는 로그인 세션 유지를 위해 쿠키를 사용합니다.  
브라우저 설정에서 쿠키를 거부할 수 있으나, 이 경우 로그인이 필요한 서비스 이용이 제한될 수 있습니다.
