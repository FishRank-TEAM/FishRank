## 개발 우선순위 · 진행 현황

```
1. 프로젝트 구조 세팅 (모노레포)     ✅
2. 회원가입 / 로그인                 ✅ (이메일) / ⏳ (소셜)
3. 카메라 가이드 UI + 사진 업로드    ✅
4. AI 서버 (어종 분류 + 줄자 인식)   🔄 (연동 완료, 품질 개선 중)
5. 인증 등급 산정 로직               ✅
6. 랭킹 페이지                       ✅
7. 내 기록 페이지                    ✅
8. 커뮤니티 · 대회 · 사전 · 정보     ✅
9. 모바일 앱 (Expo)                  ✅ (로드맵보다 선행)
```

## 인증 등급

| 등급 | 조건 | 랭킹 반영 |
|---|---|---|
| S | 완벽 인식, 규칙 준수 | 즉시 |
| A | 인식 완료, 신뢰도 낮음 | 반영 (표시 구분) |
| B | 인식 실패 또는 규칙 위반 | 미반영 (재촬영 안내) |
