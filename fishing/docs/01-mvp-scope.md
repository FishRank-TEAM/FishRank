# MVP 범위 정의서

> **목적**: 개발 범위를 명확히 해서 "범위 크리프(scope creep)"를 방지한다.

---

## MVP 기준 원칙

- **만든다**: 핵심 가치 검증에 꼭 필요한 것
- **안 만든다**: 나중에 추가해도 서비스 검증에 영향 없는 것
- **고민한다**: 우선순위 조정 필요한 것

---

## 만든다 ✅

### 1단계 - 업로드 + AI 측정 (핵심)

| 기능 | 상세 |
|---|---|
| 회원가입 / 로그인 | 이메일 + 소셜(카카오) 로그인 |
| 카메라 가이드 UI | 촬영 규칙 4가지 오버레이 안내 |
| 사진 업로드 | 파일 업로드 (카메라/갤러리 선택) |
| 촬영 규칙 검증 | 업로드 전 4가지 규칙 체크 가이드 제공 |
| 줄자 눈금 인식 | OpenCV로 눈금 추출 → 길이 계산 |
| 어종 분류 | YOLO 모델로 어종 자동 판별 |
| 인증 등급 부여 | S / A / B 등급 자동 산정 |
| 기본 랭킹 페이지 | 어종별 / 주간 TOP 10 |
| 내 기록 페이지 | 개인 업로드 기록 목록 |
| **커뮤니티** | 글쓰기, 댓글, 작성자 프로필 연동 |
| **공개 프로필** | 낚시 기록 + 작성 글 노출 |
| **대회** | 목록, 상세, 참가, 어드민 관리 |
| **어종 사전** | 어종별 정보 조회 |
| **낚시 정보** | 날씨, 매듭, 금지구역, 안전 수칙 |

### 촬영 규칙 4가지 (이 조건 위반 시 가이드 강제 표시)

```
1. 물고기를 바닥에 놓기
2. 위에서 수직으로 촬영
3. 줄자 + 물고기 함께 나오게
4. 머리 끝 + 꼬리 끝 전부 보이게
```

## 안 만든다 ❌ (아직 미구현 · Phase 이후)

| 기능 | 이유 |
|---|---|
| AR 교차검증 | 웹에서 LiDAR 접근 불가, Phase 2로 이월 |
| 팔로우 / 피드 | SNS 기능은 Phase 2 |
| 푸시 알림 | 앱 고도화 후 |
| 유료 대회 | 트래픽 확보 후 |
| 포인트 / 재화 | 사용자 기반 확보 후 |
| 공식 측정판 제작 | 하드웨어 생산 여력 없음 |
| iOS/Android 스토어 출시 | Expo 앱은 구현됨. 스토어 배포는 Phase 3 |

### 원래 “안 만든다”였으나 구현됨
- **어드민 UI** — 검수·신고·대회·유저·종 관리 등 웹/모바일 제공
- **모바일 앱 (Expo)** — 카메라 인증 업로드 포함, 웹과 기능 패리티
- **지역별 랭킹** — Phase 2 예정이었으나 선행 구현

## 인증 등급 기준

| 등급 | 조건 | 처리 방식 |
|---|---|---|
| **S** | 줄자 인식 완료 + 오차 없음 | 랭킹 즉시 반영 |
| **A** | 줄자 인식 완료 + 소폭 오차 (1~3cm) | 보정 후 반영 |
| **B** | 줄자 인식 실패 또는 오차 큼 | MVP에선 업로드 반려 |

> **MVP 단순화**: B등급 수동 검수 기능은 초기 미구현. 인식 실패 시 재촬영 안내만 제공.

## 랭킹 점수 공식

```
rank_score = length_cm × rarity_weight
```

## 개발 순서 (우선순위) · 진행 현황

```
1. 프로젝트 구조 세팅 (모노레포)     ✅
2. 회원가입 / 로그인                 ✅ 이메일 / ⏳ 소셜
3. 카메라 가이드 UI + 사진 업로드    ✅ (웹 + 모바일)
4. AI 서버 (어종 분류 + 줄자 인식)   🔄 연동 완료, 품질 개선 중
5. 인증 등급 산정 로직               ✅
6. 랭킹 페이지                       ✅ (어종·주간·지역)
7. 내 기록 + 프로필 페이지           ✅
8. 커뮤니티 (글, 댓글)               ✅
9. 대회, 어종 사전, 낚시 정보        ✅
```

## 완료 기준 (Definition of Done)

MVP가 완성됐다고 볼 수 있는 최소 조건:

- [x] 사용자가 사진을 올리면 어종과 길이가 자동으로 나온다
- [x] 길이 기반 랭킹이 어종별로 보인다
- [x] 조작 방지를 위한 인증 등급이 부여된다
- [x] 커뮤니티에 글을 쓰고, 프로필에서 내 글을 확인할 수 있다
- [ ] 실제 낚시인 5명 이상이 불편 없이 사용할 수 있다

> **2026-08 기준**: 제품 기능 DoD 1–4는 충족. 실사용자 검증(5)과 AI 분류 정확도 목표(top-1 80%)는 진행 중.
