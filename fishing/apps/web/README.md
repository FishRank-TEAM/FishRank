# FishRank Web

Next.js 16 프론트엔드입니다. 랭킹, 대회, 커뮤니티, 어종 사전, 날씨, 출조 지도, 자랑 기록, 관리자 화면이 있습니다. 공식 줄자 인증 업로드는 이 웹에서 꺼져 있고, `/upload`는 모바일 앱 안내입니다.

## 로컬 실행

```bash
# fishing/ 디렉터리에서
npm run web
```

http://localhost:3000
